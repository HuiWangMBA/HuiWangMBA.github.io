# Whitney Wang — GitHub Pages Portfolio

## Publish updates
1. Open your `HuiWangMBA.github.io` repository.
2. Choose **Add file → Upload files**.
3. Upload `index.html`, `styles.css`, `script.js`, and the `assets` folder from this package.
4. Confirm **Replace** when GitHub detects existing files, then select **Commit changes**.
5. Wait 1–3 minutes and refresh https://huiwangmba.github.io/
