# Whitney Wang — GitHub Pages Portfolio

A responsive personal portfolio for Program Management, Business Operations, Partnerships, Marketplace Operations, Business Development, and Customer Success roles.

## Before publishing

Open `index.html` and replace these two placeholder links near the Contact section:

- `https://www.linkedin.com/` with your full LinkedIn profile URL
- `https://github.com/` with your GitHub profile URL

You can also update the email, phone number, wording, and resume PDF in the `assets` folder.

## Publish with GitHub Pages

1. Create a public GitHub repository named `yourusername.github.io`.
2. Upload all files and folders from this package to the repository root.
3. Commit the files.
4. Open the repository’s **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select the `main` branch and `/ (root)`, then save.
7. Your site will appear at `https://yourusername.github.io` after deployment finishes.

For a project repository with another name, the URL will usually be `https://yourusername.github.io/repository-name/`.

## Files

- `index.html` — page content
- `styles.css` — visual design and mobile responsiveness
- `script.js` — navigation and dynamic copyright year
- `assets/Whitney_Wang_Resume.pdf` — downloadable resume
- `.nojekyll` — tells GitHub Pages to serve the files directly
